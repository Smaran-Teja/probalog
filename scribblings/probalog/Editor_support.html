2 Editor support🔗

Probalog programs can be written in a ".rkt" file like any other Racket module, but the language also claims the extension ".pdl", which is what an editor keys off of when it has no other way to know what it is looking at.

DrRacket needs nothing beyond the language itself. It reads the coloring, indentation, and interaction behavior from the #lang line, so a Probalog file opened in DrRacket gets:

  • Syntax coloring in Probalog’s own terms: predicate names as keywords, variables as symbols, quoted strings and probabilities as constants, and % comments as comments.

  • Indentation that understands statements. A rule broken across lines aligns under its first body clause, and a line following a completed statement returns to the margin.

  • Check Syntax arrows for both variables and predicate names, so Rename and Jump to Binding work on either. A variable is bound by its first occurrence in its rule’s body — the one that actually ranges over the database — and used by the others, including the ones in the head. A predicate is bound file-wide by the first statement that defines it, a fact declaration or a rule head, and used by every body clause, query, and observation that names it, so selecting one occurrence highlights the rest.

  • An interactions area that reads Probalog statements, submitting on a period rather than on a balanced parenthesis. Racket expressions are accepted there too: the saturated database is bound to probalog-result, and the whole engine interface is in scope.

  • Errors highlighted where they occur, rather than reported against the parser’s own source.

VS Code needs two separate things, because nothing there reads a #lang line the way DrRacket does. Diagnostics, hover, and jump-to-binding come from racket-langserver, which runs the same Check Syntax pass documented above and so reports the same information; it works on ".rkt" files with no additional setup. Syntax coloring comes from the extension in "probalog/vscode", which is installed by linking it into the extensions directory:

$ ln -s "$(pwd)/probalog/vscode" ~/.vscode/extensions/probalog

and restarting VS Code. It colors ".pdl" files. A Probalog program saved as ".rkt" will still be colored as Racket, since the Racket extension claims that extension and grammars are selected by file type rather than by language line.
